PandaTuner

Liste de chaînes

L'écran « Ajouter un syntoniseur » de Jellyfin n'affiche pas l'adresse de la liste pour ce type de syntoniseur : c'est ici qu'on la règle. Le bouton crée le syntoniseur PandaTuner, ou le met à jour s'il existe déjà. Les fournisseurs de guide (XMLTV) ne changent pas.

Lecture

Chaque chaîne choisit son mode avec l'attribut panda-mode dans la liste M3U :

  • direct : lecture directe pour les navigateurs (ordinateur et téléviseur) et les lecteurs natifs ;
  • app : lecture directe seulement pour les lecteurs natifs ;
  • proxy : toujours par le serveur.

Les autres applications (Swiftfin, applications inconnues) passent toujours par le serveur.

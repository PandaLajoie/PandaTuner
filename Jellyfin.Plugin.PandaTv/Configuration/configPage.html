PandaTuner

Le syntoniseur « M3U Panda » s'ajoute dans Télé en direct → Ajouter un syntoniseur. Chaque chaîne choisit son mode avec l'attribut panda-mode dans la liste M3U :

  • direct : lecture directe pour les navigateurs d'ordinateur et les lecteurs natifs ;
  • app : lecture directe seulement pour les lecteurs natifs (sources qui bloquent les navigateurs, ex. Pluto) ;
  • proxy : toujours par le serveur.

Les autres applications (navigateurs de téléviseurs, Swiftfin, applications inconnues) passent toujours par le serveur.
